# IPv6 Periphery

Static site for the IPv6 Periphery project and its INFOCOM 2025 paper.

## Local Preview

Run a simple web server from the repository root:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8000/` in your browser.

## Notes

- The site is deployed from the repository root on GitHub Pages.
- Generated `src/` artifacts are ignored by Git.
