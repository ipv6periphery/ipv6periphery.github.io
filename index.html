IPv6 Periphery Service

We provide an IPv6 Periphery Service where we publish responsive IPv6 periphery addresses to interested researchers. Access to the complete database is granted by application.

Apply for Access

We provide query access to our complete scan database for in-depth research on IPv6 network periphery, including concrete IPv6 addresses.

Access is granted by application and is free of charge for research purposes. Approved applicants receive a key that grants query access to the complete scan database. To apply, send a quick application email.

For commercial use, please contact us for further consultation.

Software and Tools

During our IPv6 periphery analysis we developed and used the following tools. We publish them for use by the scientific community:

YMap

A modular Internet IPv6 scanner.

YMap

YMap is a modular IPv6 single-packet scanner written in modern C++ (C++20). It is designed for Internet-wide IPv6 periphery discovery, and is also useful for IPv6 research, security testing, and topology analysis.

  • Single-packet scanning
  • Two scan modes: iplist (address list) and prefix (network prefix expansion)
  • Pluggable probe modules
  • Multi-threaded sending with token-bucket rate limiting
  • Real-time monitoring dashboard

Source: github.com/latteyt/ymap
